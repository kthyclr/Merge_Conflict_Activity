# GitHub Merge Conflict Activity

## Description

This repository is used to demonstrate a GitHub merge conflict by modifying the same part of the same file in two separate branches.

## Activity

The activity demonstrates:

- Creating separate branches
- Making different changes to the same line
- Merging branches
- Encountering a merge conflict
- Resolving the conflict
- Committing the resolved version
- Pushing the final version to GitHub

## Files

- `index.html` - HTML file used for the merge conflict demonstration.
- `README.md` - Documentation for the activity.

## Branches

The branches used in this activity are:

- `main`
- `conflict-branch-a`
- `conflict-branch-b`

## Conflict Demonstration

The following line in `index.html` will be modified differently by both branches:

> This line will be changed by both branches.

The conflicting changes will be resolved and merged into the `main` branch.
